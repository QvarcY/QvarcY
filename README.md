## About me

I'm **Ingars / QvarcY** from Latvia.

I'm not tied to one programming language, framework, or field.  
What interests me most is understanding how something works, finding the part that could work better, and building a practical solution around it.

That can mean:

- creating research and automation tools;
- building local-first desktop applications;
- developing PrestaShop modules;
- automating Minecraft workflows;
- experimenting with AI-assisted systems;
- working with 3D printing, laser engraving and CAD;
- or solving a small problem simply because it looked worth solving.

A lot of my projects begin with one question:

> **Could this be done better?**

If the answer looks interesting enough, I usually start building.

**Know before you print.**

A local-first Windows desktop tool for inspecting `.3mf` projects from Bambu Studio and OrcaSlicer before printing.

## How I like to build

I prefer tools that are:

**Practical**  
They should solve an actual problem rather than exist only as a technical demonstration.

**Understandable**  
A useful tool should explain what it is doing instead of hiding everything behind a black box.

**Safe by default**  
Original files, user data and existing workflows should not be casually destroyed or overwritten.

**Local-first when practical**  
Not every problem needs another cloud dependency, subscription or external service.

**Open where it makes sense**  
If something can be useful to other people, I like the idea of making at least part of it available to explore, reuse or improve.
