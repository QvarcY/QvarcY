## About me

I'm **Ingars / QvarcY** from Latvia.

I'm driven more by curiosity than by a single technology or field.

I enjoy exploring how things work, learning new technologies, understanding processes and looking for problems that can be solved in a simpler or more useful way.

Sometimes that means building a Minecraft automation tool.
Sometimes it means creating a PrestaShop module.
Sometimes it means experimenting with web technologies, 3D printing, laser engraving or CAD.

A lot of my projects start with one of these thoughts:

> **“Why does this have to be so complicated?”**

or

> **“Could this be done better?”**

I like projects that have a practical purpose — especially when they can save time, simplify a process or help someone solve a real problem.
